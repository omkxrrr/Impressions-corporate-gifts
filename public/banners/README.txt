===================================================================
IMPRESSIONS CORPORATE GIFTING - BANNER IMAGES FOLDER
===================================================================

Yaha aap apne custom banner images (Diwali, New Year, Festive offers, etc.) save kar sakte hain.

Example:
1. Apna Diwali banner design (Canva / Photoshop se) yaha save karein:
   File path: public/banners/diwali-banner.jpg
   (Recommended size: 1200 x 650 px ya 1920 x 800 px)

2. Phir src/pages/Home.jsx me HERO_BANNERS array me set karein:
   bannerImg: '/banners/diwali-banner.jpg'

Bas! Aapka custom graphic banner homepage par live dikhne lagega.
